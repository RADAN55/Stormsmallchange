# Storm Small Change — One Small Change (Keystone Habits)

Interactive 90-minute EL lesson (grades 9–12, ELPA21 Levels 3–4), Lesson 2 of the habit series at Laurel High School. Part of the Storm Studio / EL Publishing resource ecosystem.

**Live page:** https://radan55.github.io/stormsmallchange/  
**Agenda board:** https://radan55.github.io/stormsmallchange/agenda.html  
**Lesson 1:** https://radan55.github.io/stormhabit/

What's inside: bell ringer, domino-chain sketchpad, hook poll, 60-second streak lab, Kurzgesagt video with autograded checks, read-aloud passage with self-checking stop-and-jots, vocabulary notebook and matching game, if/then grammar move, keystone plan, five ELPA21-style test prep items with audio, ELPA21-aligned writing rubric, O·R·E·A·C exit ticket, progress bar, and a full report sent to Jotform.
